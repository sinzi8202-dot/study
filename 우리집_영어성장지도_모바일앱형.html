공식 잠수네 커리큘럼이 아닌 듣기·읽기 중심의 가정용 맞춤 플래너입니다.

📱 휴대폰 홈 화면에 앱처럼 추가하는 방법

아이폰 Safari: 이 HTML을 HTTPS 웹주소로 게시한 후 Safari에서 열기 → 공유(□↑) → 홈 화면에 추가 → 추가.

안드로이드 Chrome: 게시된 웹주소 열기 → 메뉴(⋮) → 홈 화면에 추가 또는 앱 설치.

다운로드한 로컬 HTML만으로는 정식 설치형 앱(PWA)이 되지 않습니다. 웹에 게시하면 홈 화면 아이콘과 독립 실행 화면을 사용할 수 있습니다. 외부 영어 학습 사이트는 인터넷 연결이 필요합니다.

① 아이와 영어 수준 선택

수준을 바꾸면 학습 콘텐츠가 달라집니다. 나이가 아니라 실제 듣기 수준을 우선하세요.

② 6개월 학습 일정

③ 이번 주 영어책·영상 카드

콘텐츠 카드의 ‘바로 학습’을 누르면 무료 제공 사이트가 열립니다. ‘자료 모음’은 해당 사이트에서 작품을 한 번 더 골라야 합니다. 공식 페이지 미리보기를 보여줍니다. 실제 개별 책 표지·영상 썸네일로 검증되지 않은 이미지는 표지라고 표시하지 않습니다. 사이트가 내부 재생을 차단하면 공식 사이트에서 열어 학습하세요.

④ ⭐ 내 즐겨찾기

즐겨찾기는 이 브라우저에 저장됩니다. 아이별로 별도 관리합니다.

⑤ 6개월 운영 방법

1~2개월: 노래·그림책으로 듣기 습관 → 3~4개월: 그림책 오디오와 집중듣기 → 5~6개월: 쉬운 이야기 이해와 반복 읽기.

같은 콘텐츠를 여러 번 반복하는 날도 포함됩니다. 7세는 하루 약 15~25분, 9세는 20~35분을 출발점으로 삼되 아이의 흥미에 맞게 조절하세요.

일부 사이트는 무료 회원가입이 필요하거나 콘텐츠 접근 방식이 변경될 수 있습니다. 외부 페이지의 영상 재생은 해당 제공처에서 이루어지며, 이 HTML에 저작권 콘텐츠를 복제하지 않습니다.
